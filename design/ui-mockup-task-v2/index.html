排序与状态口径

所有 Tab 均按创建时间降序展示。进行中不含冲突任务；已完成只展示不再需要执行的死任务（一次性完成 / 重复次数已用尽）。

列表只做状态标记

冲突任务与其它记录同构：状态图标 + 单行标题 + 单行元信息。冲突原因与处理入口全部收进详情抽屉，点记录进入。

批量删除

长按进入多选后，操作统一为底部双按钮：删除（数量）+ 取消；移除右上角图标删除与取消。

语音规划同页浮层

录音不跳转新页面，在底部浮层内完成；可先打字，录音内容追加到光标处不覆盖；停止键单层环 + 红方块（红方块按内层尺寸）。

铃铛 = 提醒方式

右上角铃铛点击设置：静音 / 语音播报互斥，震动独立开关可与任意一方同时开启；语音播报时提供提醒音量调节。

详情与编辑

详情抽屉即可编辑表单：字段直接点击修改，底部与其它浮层一致为单一「完成」按钮，保存后自动返回列表；另提供正常（非冲突）任务表单页。
