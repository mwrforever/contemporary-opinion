# 时说 · 真机冒烟清单（阶段 1 核心闭环）

> 用途：阶段 1 完成后，在 Android 真机上逐项验证核心闭环；每项记录 通过/失败 + 机型 + 备注。
> 前置：安装 `build/app/outputs/flutter-apk/app-debug.apk`（或 release 包）；通知权限允许。

## A. 账户闭环

- [ ] 首次启动展示品牌页「时说」，约 1.2s 后进入登录页
- [ ] 注册新账号成功，自动进入主界面
- [ ] 重启 App 直达任务列表（不展示品牌页）
- [ ] 用户名重复注册报「用户名已被占用」
- [ ] 密码错误登录报「用户名或密码错误」
- [ ] 「我的 → 退出登录」后回到登录页

## B. 任务闭环（手动）

- [ ] 新建任务：指定时间（明天 10:00）
- [ ] 新建任务：倒计时 30 分钟（重复次数 1）
- [ ] 新建任务：倒计时重复「每 30 分钟 × 5 次」（DELAYED）
- [ ] 过去时间被拦截（SnackBar 提示）
- [ ] 重复任务：每天 / 工作日 / 自定义星期
- [ ] 列表筛选角标计数正确（全部/进行中/冲突/已完成，待办/逾期已移除）
- [ ] 所有 Tab 按创建时间降序展示（新任务在前）
- [ ] 记录行：状态图标 + 单行标题省略；冲突仅行内标记；点击进详情抽屉
- [ ] 详情抽屉：字段可编辑、冲突原因卡（确认覆盖/改时间换资源）、单一「完成」保存自动返回
- [ ] 详情抽屉可标记完成；重复任务「完成今天」后保持待执行
- [ ] 滑动删除出现二次确认；长按进入选择模式 → 底部「删除（N）/ 取消」批量删除
- [ ] 已完成 Tab 只展示不再执行的死任务（一次性完成 / 倒计时重复达上限）

## C. 冲突检测

- [ ] 两条任务同一时段占用同一资源（如会议室A）→ 新任务红框「资源冲突」且不生效
- [ ] 点击「确认覆盖」后恢复生效、徽标消失
- [ ] 「改时间/换资源」编辑保存后重检，冲突解除自动生效
- [ ] 仅时间重叠（资源不同）→ 正常生效、不标红

## D. 提醒与响铃

- [ ] 通知权限请求出现，允许后系统级精确提醒（应用被杀仍弹）
- [ ] 到点弹通知 + 应用存活时响铃（alarm 会话，勿扰下仍出声）+ 中文播报
- [ ] 首页铃铛 → 提醒方式：静音/语音互斥、震动可叠加、音量滑杆生效
- [ ] 静音模式下到点不播报声音（仅系统通知）
- [ ] 「我的 → 提醒设置」引导页展示三项清单
- [ ] 小米/华为等机型完成电池优化/自启动放行后后台提醒仍触发

## E. 备份与数据

- [ ] 「我的 → 导出数据」生成 JSON 备份（可用文本工具打开，无密码哈希）
- [ ] 卸载重装后注册同账号，导入备份恢复任务
- [ ] 损坏文件导入报「备份文件格式不正确」

## F. 主题与稳定性

- [ ] 浅色/深色跟随系统切换，Token 对比度正常
- [ ] 竖屏锁定；刘海/挖孔屏 SafeArea 正常
- [ ] 连续增删改 50 条任务无崩溃、无卡顿

## G. 语音规划（阶段 2）

- [ ] 文本框可输入口语（离线输入法语音转文字）；录音按钮同页浮层内常驻
- [ ] 语音规划为同页底部浮层（不跳转页面）；可先打字，录音内容追加到光标处不覆盖
- [ ] 录音中：单层环 + 红方块停止键；上方耳朵 + 音波动效（振幅随音量）
- [ ] 输入「明早9点用会议室A开会两小时」→ 解析出任务卡，时间/资源正确
- [ ] 与既有任务同资源冲突 → 预览红框「冲突待处理」；「确认覆盖/改时间/换资源」可用
- [ ] 无时间任务 → 黄框「时间待定」，可设时间
- [ ] 已过去任务 → 红框且默认跳过；确认添加后任务列表出现结果反馈卡
- [ ] 一次口语多条任务 → 预览全部条目，确认添加后全部入库（缺陷回归：多任务只保存一个）
- [ ] 倒计时重复口语（如「每半小时提醒喝水共五次」）→ DELAYED 任务按间隔重复
- [ ] （可选）配置 DASHSCOPE_API_KEY 后：录音→识别→解析链路可用

## H. 记事本（阶段 3）

- [ ] 底部「记事本」进入 2 列 Hub，六卡条目数正确
- [ ] 购物：新建购物车 → 添加购物项 → 删购物车后项回收「未分组」
- [ ] 收支：记一笔收入/支出，汇总卡金额正确；报表（日/月/年）柱状图渲染
- [ ] 读书：新增书目（状态/评分）
- [ ] 旅游：新建行程 → 加一天 → 加打卡点 → 列表显示天数/打卡/费用
- [ ] 学习：新增课程 → 进课程追加记录 → 删除记录
- [ ] 菜谱：收藏（配料/步骤/难度/评分）→ 编辑 → 删除
- [ ] 购物消费趋势报表入口可用
- [ ] 旧版数据（如有）登录后自动迁移进 SQLite
