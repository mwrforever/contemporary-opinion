## 一、用户口径（2026-08-06 冒烟清单，已锁定）

1. 创建子购物车去掉「预期/差值」设计，只保留 **实付金额、条目数、创建时间**；表结构需调整。
2. 点击子购物车进入**子界面**展示购物项（层级感），不再全部平铺。
3. 增加**编辑子购物车**功能；新建时标题默认 **yyyy年mm月dd日**。
4. 子购物车列表记录**单行不换行**。
5. 记事本新增/编辑全部用**抽屉（底部弹层）**；类型枚举给生活常用项（购物项类型/消费类型/旅游交通类型等）；日期必须用**选择器**，禁止手打。
6. （第二轮）枚举子项较多时**每个枚举项最多展示两行，其余折叠、可展开**。
7. （第二轮）报表增加**分类花费占比饼图**；周期支持**按天/按月/按年**（移除按周），选中的是**单一时间单位**（某天/某月/某年）而非区间，默认当前时间所在周期，**不允许进入未来**；已有统计设计同步调整。

## 三、表结构调整提案

### 3.1 shopping_items（v4 重建）

现状（v2 创建）：

| 列 | 现状 | 调整 |
|----|------|------|
| id / user_id / cart_id / item / note / date / created_at | 保留 | 不变 |
| expected_price | 预期价 | **删除** |
| actual_price | 实付价 | **改名 `price`**（单一实付金额，REAL NOT NULL DEFAULT 0） |
| category | 自由文本 | **改为枚举 TEXT**（取值见 §四，单选，默认「其他」） |

### 3.2 shopping_carts（不变）

现状 `id / user_id / name / note / created_at` 已满足新口径：列表行的实付金额与条目数为聚合值（SUM/COUNT，不必物化列）；「创建时间」即 created_at；标题默认日期即可，**不新增 shopping_date 列**（标题即承载日期语义；用户改名后不再追溯日期）。

### 3.3 数据库迁移（v3 → v4）

- `_dbVersion` 3 → 4，新增 `_upgradeV4`：重建 `shopping_items`（SQLite 删列需建新表 → 拷数 → 删旧 → 改名）。
- 数据映射：`price = CASE WHEN actual_price > 0 THEN actual_price ELSE expected_price END`（实付优先；旧数据实付为 0 时以预期价兜底，避免丢失唯一金额信息）——**待确认**。
- 旧 Hive 迁移（`legacy_notebook_migration.dart`）：`NotebookShopping.fromJson` 保留旧键读取兼容（expected_price/actual_price），写入只落新表；迁移完成后新模型不再持有 expected 字段。
- 关联影响：报表入口（购物消费趋势）聚合字段 `actualPrice` → `price`，报表 UI 不变；`test/notebook_store_test.dart` / `test/notebook_ui_test.dart` 随实现同步更新。

## 四·B、报表改版设计（第二轮新增）

### 交互

- 周期粒度：**按天 / 按月 / 按年** 分段控件（移除按周）。
- 选中**单一时间单位**而非区间：按天=某一天（如 8月6日）、按月=某个月（如 2026年8月）、按年=某一年（如 2026年）。
- 时间选择：默认当前时间所在周期（今天 / 本月 / 今年）；切换粒度时回到当前周期；点击导航中间字段弹出对应选择器（日历 / 月份 / 年份），禁止手打。
- 周期导航：左箭头查看往期；**右箭头在当前周期时禁用**（灰态），选择器亦不可选未来，不允许进入未来统计。
- 无数据：显示空态提示（这一时期还没有数据）。

### 可视化

- 主图：**环形饼图**（自绘 conic-gradient/SVG，不引入图表库），展示各**分类花费占比**，中心显示本周期总花费。
- 图例：色点 + 分类名 + 金额 + 百分比（不依赖单一颜色表达）。
- 汇总卡：本周期**总花费 / 条目数 / 分类数**（原「日/月/年 6 桶柱状图」调整为分类占比视角；购物消费趋势入口行为收敛为本屏）。
- 分类配色：固定分类调色板（accent/warn/ok/danger + 中性灰），深色模式同套语义色。

### 数据口径

- 聚合字段：`price`（实付金额，v4 表结构），按 `category` 分组、按周期过滤；无分类（空串）归入「其他」。
