## 二、设计原则

1. **温暖、聪明、不焦虑**：品牌调性来自 `docs/brand_design.md`，避免 AI 紫蓝与纯黑工具感。
2. **单一强调色**：青绿 `#0E8C7F` 全局唯一强调；danger/warn/ok 仅用于业务语义状态，不参与装饰。
3. **状态可视化优先**：冲突阻断、时间待定、弱提醒、已过去四态必须有边框/徽标/文案三重表达，不依赖单一颜色。
4. **触控优先**：可点目标 ≥48×48pt，按压反馈 150–200ms、缩放 0.97。
5. **深色模式**：Token 反演（跟随系统），不另起一套设计。

## 四、字体与排版

### 4.1 字体

- **中文**：系统字体栈，不打包第三方字体（体积与渲染稳定优先）：
  `PingFang SC`（iOS）→ `MiSans` / `HarmonyOS Sans SC`（Android）→ `Noto Sans SC`（兜底）。
- **拉丁/数字**：`Inter` 可选随包；未打包时回退系统无衬线。时间、金额等数字建议等宽特性（`fontFeatures: tabular figures`）。
- **品牌字「时说」**：52 / 800 / 字距 +4（沿用品牌文档）。

### 4.2 字号层级

| 层级 | 字号/字重 | 场景 |
|------|----------|------|
| 页面大标题 | 20 / 800 | 页面标题（任务列表日期行、各页 AppBar） |
| 卡片标题 | 15–16 / 600–700 | 任务标题、hub 卡片名 |
| 正文 | 14–16 / 400（行高 1.5） | 表单、说明 |
| 辅助 | 12–13 / 400–500 | 元信息、时间、角标文字 |
| 按钮 | 16 / 600 | 主操作 |

## 五、圆角 / 间距 / 阴影 / 动效

- 圆角：卡片 20、按钮 14、输入框 12、chip 999。
- 间距基准：4 / 8 / 12 / 16 / 24 / 32（8pt 网格）。
- 阴影：低扩散（`0 2px 10px rgba(16,19,21,.06)`），深色模式关闭阴影。
- 动效：150–200ms；按压缩放 0.97；品牌页淡入；尊重系统减弱动效。

## 七、核心页面与关键交互态

1. **登录/注册**：本地校验；密码显隐；用户名唯一错误就近提示；品牌首启展示「时说」。
2. **任务列表**：筛选 Tab（全部/进行中/待办/逾期/冲突/已完成 + 角标）；滑动删除二次确认；长按选择模式；Speed Dial。
3. **添加任务**：分区表单；SegmentedButton 指定时间/倒计时；重复 Dropdown + 自定义星期 chips；资源/时长/响铃；过去时间 SnackBar 拦截。
4. **语音预览四态**（核心）：
   - 冲突待处理：红框 + 红徽标 + 「确认覆盖 / 改时间 / 换资源」；
   - 时间待定：黄框 + 黄徽标 + 「设时间」；
   - 仅时间重叠：卡片正常，黄字弱提醒文案；
   - 已过去：红框 + 灰徽标 + 「保存跳过」。
5. **记事本 Hub**：2 列网格，六子功能条目数速览；语义色块（青绿/绿/黄）区分但保持同一语言。
6. **收支报表**：日/月/年 SegmentedButton；收入绿/支出红 6 桶堆叠柱状图；结余总览卡。
7. **我的**：资料编辑、默认响铃时长、导出/导入（JSON）、深色模式跟随系统、退出登录。
8. **提醒引导**：通知权限 / 电池优化 / 自启动三项清单，被拒引导到系统设置。

## 八、语音「识别中」与错误态

- 识别中：AppBar 右侧黄色「识别中…」徽标 + 转录卡 + 解析进度。
- 失败/超时：SnackBar 中文提示 + 「重试」；离线无 Key 时回落本地 `nlp_parser.dart`（产品行为，UI 同预览卡）。
