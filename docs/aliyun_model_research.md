## 一、语音识别类模型

### 1. 智能语音交互 · 实时语音识别（Paraformer 大模型）
- **功能定位**：阿里云官方语音 AI 产品，提供一句话/实时/录音文件识别，底层为 Paraformer 大模型。
- **适用场景**：移动端实时短语音输入的成熟方案；官方提供 iOS / Android / HarmonyOS SDK 与合规配置文档，适合对移动端集成与合规要求高的生产环境。
- **定价（后付费，按时长阶梯）**：实时语音识别 ¥3.50/小时（0–299h）→ ¥1.20/小时（>5000h）；短句识别 ¥3.50/1000 次；录音文件识别 ¥2.50/小时（阶梯至 ¥1.00/小时）。
- **来源**：https://help.aliyun.com/en/isi/product-overview/billing-10

### 2. 大模型服务平台百炼 · fun-asr-realtime（Paraformer 实时语音识别）
- **功能定位**：百炼平台上的 Paraformer 实时语音识别模型，按音频秒数计费，支持流式。
- **适用场景**：与通义千问同处百炼平台，可用同一 API Key / SDK 调用；按秒计费、成本极低，适合 C 端高频实时识别。
- **定价**：¥0.00033/秒（中国内地），开通百炼后 90 天内赠送 36,000 秒（10 小时）免费额度；国际 ¥0.00066/秒。另有 Paraformer 录音文件 `paraformer-v2` ¥0.00008/秒（每月免费 36,000 秒）。
- **来源**：https://help.aliyun.com/zh/model-studio/developer-reference/billing-for-text-rerank

### 3. 通义听悟（Tongyi Tingwu）
- **功能定位**：聚焦音视频内容理解与会议纪要与「待办事项」提取的 AI 助手 / 平台。
- **适用场景**：会议 / 访谈等长音频的转写 + 智能纪要（含待办提取）。偏向「会议纪要式」产出，结构化 JSON 自由度不如直接调 LLM。
- **定价**：ASR ¥0.6/小时；智能纪要-大模型分析 ¥0.064/小时/能力（待办事项为其中一项）。新用户 90 天免费试用，实时每天 48h、文件每天 2h 免费额度。
- **来源**：https://help.aliyun.com/practice_detail/460677 、 https://helpcdn.aliyun.com/document_detail/2974664.html

## 二、任务排期生成 / 文本理解类模型

### 1. 通义千问 qwen-plus（百炼）
- **功能定位**：通义千问系列中性价比最高的通用大模型，支持结构化输出（JSON）、function calling、联网搜索。
- **适用场景**：把自然语言（语音转写文本）转换为结构化任务排期表 JSON——qwen-plus 的结构化 / JSON 输出能力正好满足；成本极低、延迟小，适合高频调用。
- **定价**：输入 ¥0.8/百万 tokens（¥0.0008/千），输出 ¥2/百万 tokens（¥0.002/千）；百炼开通 90 天内各 100 万 token 免费。
- **来源**：https://help.aliyun.com/zh/model-studio/model-pricing 、 https://www.aliyun.com/product/bailian

### 2. 通义千问 qwen-max / qwen3-max（百炼）
- **功能定位**：通义千问旗舰模型，复杂中文长文本理解与多约束推理更强。
- **适用场景**：超长 / 复杂语音转写文本、含多约束（资源、依赖、优先级）的排期规划，需要更强语义理解时。
- **定价**：qwen-max 输入 ¥11.743/百万（¥0.0117/千），输出 ¥46.971/百万（¥0.047/千）；qwen3-max 输入 ¥8.807/百万，输出 ¥44.035/百万。百炼开通 90 天内有免费额度。
- **来源**：https://help.aliyun.com/zh/model-studio/model-pricing

### 3. 通义听悟 · 智能纪要-待办事项（备选）
- 已在智能纪要中内建「待办事项」提取（¥0.064/小时），但输出结构固定、定制空间小，不推荐作为主排期生成引擎，可作为「会议纪要→待办」场景的现成方案。

## 三、推荐组合与理由

### ✅ 推荐生产组合（默认）
- **语音识别**：百炼 `fun-asr-realtime`（Paraformer 实时）
- **任务排期生成**：通义千问 `qwen-plus`（百炼）

**推荐理由：**
1. **统一平台**：两者均在百炼（Model Studio），一个 API Key、一套 SDK、统一账单，集成与运维成本最低。
2. **低延迟**：`fun-asr-realtime` 支持流式识别，移动端实时出字；`qwen-plus` 推理快、够用。
3. **成本可控**：语音 ¥0.00033/秒（约 ¥1.19/小时），排期 ¥0.0008/千 token 输入，对 C 端高频调用非常友好；且有 10 小时语音 + 100 万 token 免费额度可验证。
4. **结构化输出**：`qwen-plus` 支持 JSON / 结构化输出与 function calling，正好把自然语言映射成任务排期表 schema，无需自建解析。

### 🔝 质量优先备选组合
- **语音识别**：智能语音交互 实时语音识别（移动端 SDK 与合规文档最全，可更低延迟 / 离线）
- **任务排期生成**：通义千问 `qwen-max`（复杂约束理解更强）

**适用**：对转写准确率 / 移动端合规要求极高，或排期文本很长、约束很复杂的场景。

## 四、对后续实现的提示
- **冲突检测**（时间重叠 / 资源占用）、**标红**与**手动调整**逻辑与具体大模型无关，属于客户端 / 服务端编排层，可在确认模型组合后由架构师设计、工程师实现。
- **接入安全**：百炼提供 DashScope / OpenAI 兼容 API。纯前端 Flutter App 不应在前端暴露 API Key，建议加一层后端 / 云函数代理转发（架构设计阶段需明确）。
- **fallback**：排期生成建议保留「本地启发式解析」作为离线 / 配额耗尽时的兜底，保证无网也能用。
