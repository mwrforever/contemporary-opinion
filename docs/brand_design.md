# 品牌视觉规范 · 时说（Shí Shuō）

> 产品原名「每日规划助手」（内部包名 / 保底资产）。对外统一启用品牌名 **时说**。
> 本文档为品牌视觉与启动页（Splash）的设计稿，供设计 / 研发 / 运营对齐使用。

---

## 1. 品牌定位

- **一句话**：说出来，日程就有了。
- **主传播语**：**你的时间，不该撞车。**（前置最大差异化：冲突检测标红拦截）
- **副标语**：把脑子里的安排，顺成一天的秩序。
- **调性**：温暖、聪明、不焦虑——帮人把脑子里的安排理顺，而不是又一个冰冷的待办清单。

## 2. 命名逻辑

- **时** = 时间；**说** = 说话。直接亮出「用说的来规划」的差异化，呼应语音自然规划能力。
- 读音近「时新」，有鲜活感；二字轻、稳、有节奏，无工具感，避开了「XX助手/管家」的烂大街套路。

## 3. 色彩系统

沿用 App 既有设计语言（单一去饱和强调色，避开 AI 紫蓝与纯黑）：

| 角色 | 色值 | 用途 |
|------|------|------|
| 强调色 accent | `#0E8C7F`（青绿 teal） | 主按钮、品牌标识、重点信息 |
| accentSoft | `#E2F4F1` | 品牌标识圆底、浅色高亮 |
| 警示 danger | `#C0492F` | 冲突任务标红、错误 |
| 提醒 warn | `#C9782B` | 时间重叠（弱提醒） |
| 成功 ok | `#3F9D6B` | 已完成 |
| 背景（浅） | `#F6F7F4` 暖白 | 页面底；非纯白 |
| 背景（深） | `#101315` | 深色模式页面底 |

## 4. 字体与排版

- 主字体：系统字体（System），保证跨平台一致。
- 品牌字「时说」：字号 52，字重 800，字间距 +4，居中。
- 主标语：18 / 600；副标语：14 / 行高 1.6 / 55% 不透明度。
- 圆角：卡片 20，按钮 14；扩散低阴影营造「轻盈有层次」。

## 5. 品牌标识（Logo）方案

- **图形**：88×88 圆角/正圆底（`accentSoft`），中心一个声波图形 `graphic_eq_rounded`（accent 色）。
- **含义**：声波 = 语音规划；圆形 = 完整、安顿。呼应「会听、会排」。
- **简化版**：纯文字「时说」二字 + accent 色，适合小尺寸 / 应用图标占位。
- 应用图标（移动端）：`android/app/src/main/res/mipmap-*` 暂沿用占位，建议后续替换为本标识。

## 6. 启动页（Splash）设计稿

**布局（纵向居中）**：

```
        ( 声波品牌标识 ◯ )
            时  说            ← 52 / 800 / 字距4
   把脑子里的安排，顺成一天的秩序。   ← 主标语 18/600
   说出来就好——会听、会排，还会帮你避开每一次撞车。 ← 副标语 14/55%
              （弹性留白）
        [   开始规划   ]        ← 主按钮 FilledButton，accent
          你的时间，不该撞车。     ← 底部主传播语 13/40%
```

- 背景：`scheme.surface`（浅色暖白 / 深色对应）。
- 交互：点击「开始规划」→ `pushReplacement` 进入 `HomeScreen`。
- 动效：品牌标识可加轻微淡入（现有 `FadeIn` 组件可复用）；本版为静态，预留微动效空间。
- 文案对照：标题「时说」、主标语、副标语、按钮「开始规划」、底部「你的时间，不该撞车。」——均与代码 `lib/screens/splash_screen.dart` 一致。

## 7. 应用商店简介（≈110 字）

> 时说是一款用说的就能规划日程的 App。说一句"明早9点开会两小时，用三号会议室"，它就自动排好时间、识别资源、记住每周重复。最贴心的是冲突检测——两场会抢同一间会议室会立刻标红提醒，让日程永不撞车。没网也能用，离线照样帮你理顺安排。

## 8. 三句核心卖点

- **语音规划**：张嘴就说，口语秒变结构化任务，不用手填一个字。
- **智能排期**：一句话自动生成时间、资源、重复规则，排期像说话一样自然。
- **冲突检测**：会议室被重复占用立刻标红拦下，时间重叠只轻提醒，安排永不出错。
