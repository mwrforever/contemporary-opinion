**Project:** 时说

## 设计原则

1. 温暖、聪明、不焦虑；避免 AI 紫蓝与纯黑工具感。
2. 单一强调色青绿；danger/warn/ok 仅用于业务语义状态。
3. 状态可视化优先：边框 / 徽标 / 文案三重表达，不依赖单一颜色。
4. 触控优先：可点目标 ≥44×44（Android ≥48dp），按压反馈 150–200ms、缩放 0.97。
5. 深色模式：Token 反演跟随系统，不另起一套设计。

## 色彩 Token（浅 / 深）

| Token | 浅色 | 深色 | 用途 |
|-------|------|------|------|
| accent | `#0E8C7F` | `#4FBFAF` | 品牌标识、图标、选中态 |
| accent-strong | `#0A7368` | `#6CCFC1` | 主按钮底（白字对比度 ≥4.5:1） |
| on-accent | `#FFFFFF` | `#101315` | 强调色上的文字 |
| accent-soft | `#E2F4F1` | `#143834` | 品牌圆底、浅高亮、资源 chip |
| 背景 / 表面 | `#F6F7F4` / `#FFFFFF` | `#101315` / `#1A1D20` | 页面底 / 卡片 |
| 表面-2 | `#EEF1EC` | `#23272B` | 筛选条、分段控件底 |
| 文本 主/次/辅 | `#1C1E1B` / `#5C5F58` / `#8A8D85` | `#F2F3EF` / `#9EA19A` / `#6B6F68` | 三级文本 |
| danger | `#C0492F` | `#E08A74` | 冲突阻断、错误 |
| warn | `#C9782B` | `#E0A263` | 时间重叠弱提醒、待定 |
| ok | `#3F9D6B` | `#6FBF92` | 已完成、收入 |
| border | `#E2E5DF` | `#2A2E32` | 描边 |

> 危险/警告/成功均配套 soft 底（如 `#FBE9E4`），用于卡片底色但不影响文字对比度。

## 字体与排版

- 中文系统字体栈：PingFang SC → MiSans / HarmonyOS Sans SC → Noto Sans SC；拉丁/数字回退无衬线（数字建议 tabular figures）。
- 页面大标题 20/800；卡片标题 15–16/600–700；正文 14–16/400（行高 1.5）；辅助 12–13/400–500；按钮 16/600。

## 圆角 / 间距 / 阴影 / 动效

- 圆角：卡片 20、按钮 14、输入框 12、chip 999。
- 间距基准 4/8/12/16/24/32（8pt 网格）。
- 阴影低扩散 `0 2px 10px rgba(16,19,21,.06)`；深色关闭阴影。
- 动效 150–300ms；按压缩放 0.97；尊重系统减弱动效（prefers-reduced-motion）。

## 组件规范

- 按钮：主按钮 accent-strong 底 + 白字、高 52；次级/描边按钮同规格；破坏性操作用 danger。
- 卡片：surface 底 + border + radius 20 + 低阴影；状态卡用 2px 边框 + soft 底。
- 输入框：标签 + 50 高、radius 12；日期/枚举必须走选择器，禁止手打。
- 筛选 Tab：胶囊形 + 数量角标（`全部/进行中/冲突/已完成`，任务模块 V2）。
- 任务记录：状态图标打头（42px 圆角方块）+ 单行标题省略 + 单行元信息；复选框仅批量删除模式出现且独立于卡片。
- 底部导航 ≤5 项：任务 / 记事本 / 我的。
- 图标统一线性 SVG（stroke 1.9–2.2），禁止 emoji 作为结构图标。

## 禁止项

- ❌ 玻璃拟态 / 蓝紫渐变 / 高饱和装饰色
- ❌ emoji 作图标、低对比灰字（正文 <4.5:1）
- ❌ 小于 44×44 的可点目标、无按压反馈、0ms 状态突变
- ❌ 动画时长 >500ms 或未尊重减弱动效
- ❌ 手打日期/枚举输入
